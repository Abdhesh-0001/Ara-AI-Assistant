# Ara-AI-Assistant

Your all-in-one smart assistant for instant answers, real-time web search, quizzes, and live weather updates.

## 🚀 Features
- 💬 **Chat with Groq AI** – Fast AI-powered conversations
- 😂 **Jokes & Riddles** – Fun interactive prompts
- 🎯 **Quiz Game** – Interactive quiz mode
- 🔍 **Real-Time Web Search** – Live web results via DuckDuckGo
- 🎲 **Utility Tools** – Built-in dice roller and coin flipper
- 📝 **Chat History** – Persistent session memory
- 📚 **Vocabulary & Motivation** – Daily word learning and inspirational quotes
- 🕰️ **Real-Time Date & Time** – Live system clock awareness

## 🛠️ Setup Instructions

### 1. Clone the repository
```bash
git clone [https://github.com/Abdhesh-0001/Ara-AI-Assistant.git](https://github.com/Abdhesh-0001/Ara-AI-Assistant.git)
cd Ara-AI-Assistant
2. Install dependencies
Bash
pip install -r requirements.txt
3. Configure environment variables
Create a .env file in the project root directory:

Code snippet
GROQ_API_KEY=your_groq_api_key_here
WEATHER_API_KEY=your_weather_api_key_here
4. Run the application
Bash
streamlit run Ara_web.py
